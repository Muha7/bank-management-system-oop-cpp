# Bank Management System – C++

An advanced console-based Bank Management System developed using C++ and Object-Oriented Programming (OOP).

The project provides a structured banking environment with client management, user administration, role-based access control, and financial transaction operations. Data is stored persistently using text files.

## Features

### Client Management
- Add new bank clients.
- Update client information.
- Delete and search for clients.
- Display all registered clients.
- View total account balances.

### User Management
- Create, update, and delete system users.
- Search and list registered users.
- Assign permissions to different users.
- Control access to system features.

### Banking Transactions
- Deposit money into client accounts.
- Withdraw money from accounts.
- Transfer funds between clients.
- View transfer history.

### Authentication and Activity Records
- User login system.
- Permission-based access control.
- Login activity records.

### Data Persistence
- Store client and user information in text files.
- Save transaction and login records.
- Retrieve stored information when the application runs.

## Technical Details

- **Language:** C++
- **Programming Paradigm:** Object-Oriented Programming
- **IDE:** Microsoft Visual Studio
- **C++ Standard:** C++20
- **Application Type:** Console Application
- **Data Storage:** File Handling

## OOP Concepts

The project demonstrates:
- Classes and Objects
- Inheritance
- Encapsulation
- Constructors
- Getters and Setters
- Static Methods
- Enumerations
- Access Control and Permissions

## Project Structure

The application is organized into multiple header files, with separate classes responsible for client management, user management, transactions, authentication, validation, and utility operations.

## How to Run

1. Clone or download this repository.
2. Open `Bank_System_OOP.vcxproj` using Microsoft Visual Studio.
3. Make sure the required C++ development tools are installed.
4. Build the project.
5. Run the application.

Keep the required `.txt` data files in the application's working directory.

## Note

This project is developed for educational purposes and demonstrates C++ programming, OOP concepts, file handling, and basic banking operations. It is not intended for real financial transactions or production use.
